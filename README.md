# Claude auto-memory

Persistent memory voor Claude Code-sessies in de `HomeAssistant`-repo
(user/feedback/project/reference-notities). Wordt automatisch bijgehouden
door Claude zelf tussen sessies door - zie `MEMORY.md` voor de index.

Dit is geen projectcode en geen onderdeel van de homelab-infrastructuur;
zie in plaats daarvan [MkDocs](https://github.com/WilcoKakkenberg/MkDocs)
voor de eigenlijke documentatie van die infrastructuur.
